# C_Sharp_DelegatesAndLambdas_NumberProcessing

## C#_DelegatesAndLambdas_NumberProcessing

### Задание «Контрольная точка №19 — делегаты и лямбды»

Вариант 1. Обработка чисел
1. List<int> numbers с произвольным набором положительных и отрицательных чисел.
2. Лямбда-фильтр Func<int, bool>: оставляет только чётные числа.
3. Лямбда-преобразование Func<int, int>: возводит число в квадрат.
4. Два лямбда-действия Action<int>, объединённые через += в один многоадресный делегат: одно выводит результат на экран, второе сохраняет его в отдельный список.
5. Конвейер: для каждого чётного числа вычислить квадрат и выполнить объединённое действие с результатом.
